# NEXORA — Next-Gen E-Commerce

A polished, zero-build e-commerce frontend prototype designed to be easy to inspect and run directly from GitHub.

## ✦ Included

- Premium responsive storefront UI
- Product search and category filtering
- Wishlist with browser persistence
- Smart cart with quantity controls
- Quick-view product modal
- Demo checkout flow
- Natural-language “Shop by Intent” matcher
- Responsive mobile layout
- Cinematic gradients, glass effects and 3D-style hero motion
- No npm, database, API key or setup required

## ▶ Run it

Open `index.html` locally in a browser, or enable **GitHub Pages** for the repository and use the generated Pages URL.

## 🧩 Production roadmap

The frontend is intentionally dependency-free. A production version can connect:
auth → product/catalog API → inventory → orders → payments → reviews → recommendations → notifications → admin analytics.
